# TopiaForge V1 SDK

This package is part of the TopiaForge V1 mod-authoring SDK for Robotopia. It contains a reference assembly for
compile-time use; Robotopia's TopiaForge loader supplies the matching runtime implementation.

Create, restore, test, and package mods with the `topiaforge` CLI. Do not copy SDK assemblies into a mod package.
API guides and diagnostic remediation are available at https://docs.topiaforge.dev/.
