# {{DISPLAY_NAME}}

A UI mod ({{MOD_ID}}) that opens a TopiaForgeUi window with a hotkey, modeled on the UI Gallery mod.

## Quick start

1. Validate the project: `topiaforge check package .`
2. Build and package: `topiaforge pack`
3. Install into the game: `topiaforge install`
4. Play: `topiaforge launch` — press the mod's hotkey to toggle the window; **F8** opens the TopiaForgeUi gallery for reference.

## What to edit next

- `{{TYPE_NAME}}Mod.cs` — the window layout and hotkey; build windows, HUDs, modals, and toasts with the TopiaForgeUi kit.

New to modding? Follow `docs/YourFirstMod.md` in the TopiaForge repository; `docs/UiKit.md` documents the TopiaForgeUi widgets.
