# {{DISPLAY_NAME}}

A UI mod ({{MOD_ID}}) that opens a QwUi window with a hotkey, modeled on the UI Gallery mod.

## Quick start

1. Validate the project: `robotopia check package .`
2. Build and package: `robotopia pack`
3. Install into the game: `robotopia install`
4. Play: `robotopia launch` — press the mod's hotkey to toggle the window; **F8** opens the QwUi gallery for reference.

## What to edit next

- `{{TYPE_NAME}}Mod.cs` — the window layout and hotkey; build windows, HUDs, modals, and toasts with the QwUi kit.

New to modding? Follow `docs/YourFirstMod.md` in the QuantumWorks repository; `docs/UiKit.md` documents the QwUi widgets.
