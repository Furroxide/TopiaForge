## Native input, rendering, sound and resource oracles

UI actions must traverse real toolkit hit regions and input dispatch. Resolve stable widget IDs to measured bounds, then click/type through OS input; separately capture visibility, focus, control suppression and native state. Direct controller calls remain useful fixtures and fault injectors but cannot prove F5, hit testing, focus or player control restoration. Detect wrong foreground window, locked/disconnected session and changed display before actuation; abort safely and release every held key/button.

Pin game/Editor versions, camera, viewport, DPI, graphics, fonts, locale and accessibility profiles for screenshots. Use reviewed baselines, a small explicit mask for dynamic regions and quantified tolerances; retain unmasked originals privately. Test clipping/overflow, HUD persistence, contrast, scale, reduced motion and keyboard focus semantically as well as visually. Baseline changes need review; auto-accepting fresh images defeats the check.

Use approved devices and synthetic distinct cues for bounded loopback audio capture. Compare onset, expected channel/position behavior and post-Stop silence against a noise floor and timeout; keep one unrelated control cue to detect a broken recorder. Synthetic conversation fixtures prove lifecycle deterministically; separately classify actual backend/voice-device integration. Loopback capture cannot establish speaker audibility or physical microphone quality. No personal speech or credentials enter fixtures.

Native resource observers collect identities, owner IDs and counts independently of commands. Compare preconditions, immediate postconditions and post-destruction/frame barriers; use monotonic deadlines and fixed stabilization limits. Keep the first failure, input trace, snapshots, screenshots, logs and digests. Diagnostic reruns get new run IDs and cannot overwrite a failure. Cancellation attempts every cleanup, releases device input and confirms exit of only the original owned process; unconfirmed exit blocks success and preserves the layout.
