# TopiaForge 0.1.1

This is the first public-release candidate for the TopiaForge modding ecosystem for Robotopia.
It contains the desktop launcher, runtime loader, developer CLI, SDK/UI
assemblies, authoring templates, first-party mods, registry tooling, and
diagnostic utilities.

Publication remains intentionally blocked until the repository license,
platform signing, notarization, immutable-release setting, and protected
release environment have been approved and verified.
