# TopiaForge 0.2.0-rc.2

Windows x64 candidate for internal testing with Robotopia build 2640 and the staging multiplayer service.

1. Compare the ZIP's SHA-256 against `SHA256SUMS` before extracting. Keep the extracted folders together.
2. Open `launcher\topiaforge_launcher.exe` and select your Robotopia build 2640 installation. Open **Setup** to install or repair the runtime if prompted.
3. To install the bundled set at once, copy the `.topiaforgemod` files from the extracted `dist` folder to `BepInEx\TopiaForge\package-inbox` inside the selected Robotopia folder. Create that inbox folder if needed. In the launcher, open **Mods**, select **Install Inbox**, and confirm all packages were installed. To review and install one package at a time, open **Browse**, find **Bundled Local Packages**, select **Preview**, and follow **Install Plan**.
4. Return to **Home** and choose a **Launch target**. To replace an unavailable saved selection, choose an available target or **Use main menu**.

The persistent body composition change in #408 is awaiting the D11 host and remote native results. Windows executables are unsigned under the current 0.x policy.
