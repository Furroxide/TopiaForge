# TopiaForge 1.0.0

TopiaForge 1.0.0 establishes the first supported mod authoring contract. It ships the
owner-scoped SDK, manifest V4, clean-machine developer tooling, package integrity and
recovery hardening, safe gameplay and UI abstractions, testing support, and V1 module
contracts for safe game mods.

This release intentionally breaks the unreleased 0.1.x SDK surface. Existing first-party
mods and templates are migrated together; third-party compatibility was never promised.
