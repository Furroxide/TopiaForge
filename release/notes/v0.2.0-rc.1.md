# TopiaForge 0.2.0-rc.1

This Windows x64 candidate covers the launcher, CLI, runtime loader, SDK, and first-party packages for Robotopia build 2640.

## What to test

- Use the launcher to install, repair, and launch the game with a fresh profile.
- Create, restore, pack, and install a mod with the CLI.
- Check in-game menus and HUDs at different UI scales. Include keyboard navigation and focus in reports.
- Test multiplayer hosting and joining through the staging service.

## Download and verification

Check the Windows archive against `SHA256SUMS` before extracting it. Keep the archive layout intact and run `topiaforge doctor --strict` before the first game launch.

The Windows executables are unsigned under the current distribution policy. Windows may show an unrecognized-publisher or SmartScreen warning. Update metadata is signed separately.
