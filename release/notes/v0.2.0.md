# TopiaForge 0.2.0 (preparation)

The current development target is 0.2.0. This catalog entry is blocked; it is not
a published or qualified release. The RC1 catalog entry and notes remain historical.

The loader, SDK, CLI, launcher and first-party packages target the 0.2 line.
First-party loader and SDK ranges are exactly `>=0.2.0 <0.3.0`. Safe contract
assemblies retain `AssemblyVersion` `0.1.0.0`; package and file versions advance.
Existing API feature floors keep their original first-release requirements.

GameCompat, Unity companion packages, BepInEx, the updater protocol and minimum
updater version retain their independent versions. The audited game build and
platform scope are unchanged.

The existing release/security gates still apply, including signed-off commits,
protected approval, immutable assets, game qualification and isolated native
acceptance. DCO checks every incoming PR commit against its verified base,
independently of release tags and the product version. Already-integrated
base history stays outside that range.

Stable 0.2.0 does not inherit permission to ship an unsigned prerelease. Current
validation requires a prerelease, and policy still records unsigned Windows
distribution, so both gates refuse a stable version. The frozen readiness
evidence also belongs to RC1. Distribution policy, current-version readiness and native qualification require
separate review before this entry can become ready. Multiplayer enablement and
service deployment are separate gates.
