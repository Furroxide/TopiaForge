# Support

Start with `README.md`, `docs/YourFirstMod.md`, and `docs/Troubleshooting.md`. Run `topiaforge doctor` and attach the
redacted diagnostic bundle when opening a bug report. Remove account names, private paths, session files, tokens,
proprietary game assemblies, and unpublished mod content before sharing logs.

Use GitHub issues for reproducible TopiaForge defects and feature proposals. Questions about third-party mods belong
with their authors; game bugs unrelated to the loader belong with the Robotopia game publisher. Report security issues
privately as described in `SECURITY.md`.

The project currently offers best-effort community support without a response-time or long-term-support guarantee.
