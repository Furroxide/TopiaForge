# Support

Start with `README.md`, `docs/YourFirstMod.md`, and `docs/Troubleshooting.md`. Run `topiaforge doctor` and attach the
redacted diagnostic bundle when opening a bug report. Remove account names, private paths, session files, tokens,
proprietary game assemblies, and unpublished mod content before sharing logs.

Use GitHub issues for reproducible TopiaForge defects and feature proposals. Repository administrator `@furroxide` is
the interim support owner and may delegate individual reports. Questions about third-party mods belong with their
authors; game bugs unrelated to the loader belong with the Robotopia game publisher. Report security issues privately
as described in `SECURITY.md`.

The project currently offers best-effort community support without a response-time or long-term-support guarantee.
Release, incident, revocation, and rollback ownership is documented in `docs/ReleaseOperations.md`.

TopiaForge is an independent, community-built modding toolkit. It is not developed, published, or endorsed by Tomato
Cake or the Robotopia development team, and is not otherwise affiliated with them. "Robotopia" and "Tomato Cake" are
the property of their respective owners and are used here only to identify the game this toolkit works with. See
[TRADEMARKS.md](TRADEMARKS.md).

Please do not contact Tomato Cake or the Robotopia development team about TopiaForge.
